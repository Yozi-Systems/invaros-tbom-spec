# Release procedure

Before tagging a public draft, run the complete test suite and example
validator, verify Profile 3 preservation, reproduce all fingerprint and
semantic-ID vectors independently, validate repository integrity, update the
changelog, and record the exact source commit and artifact manifest. Review
public evidence for disclosure safety; never add internal-full captures.

Publication, pushing tags, changing repository visibility, and website changes
are separate maintainer actions and are not performed by the validation suite.
