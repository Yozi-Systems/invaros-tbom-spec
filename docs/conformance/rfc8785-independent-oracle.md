The primary independent JCS truth source is the upstream unmodified
`node-es6/canonicalize.js` implementation together with the six input,
canonical-output, and hexadecimal-output cases under `testdata/`. The immutable
commit, not the moving default branch, defines the approved corpus.

Phase 1 vendors those test-only files with hashes and the upstream license.
Wrappers may parse inputs, reject values outside the locked integer-only
Profile 4 domain, and compare bytes, but MUST NOT modify the upstream
canonicalizer. The oracle and Node.js are development/test dependencies only;
they MUST NOT be linked, installed, or packaged on an InvarOS target.

The Cyberphone implementation is independent of the C implementation under
test. A separate Python byte reconstruction independently checks YOZI-TID-v1,
YOZI-FP-v1, and source-content SHA-256 construction. No expected byte string is
generated by the C library it tests.
