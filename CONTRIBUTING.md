# Contributing

This is a founder-led public specification maintained by Yozi Systems.
Proposals are welcome as issues or pull requests. Explain the interoperability
problem, affected permanent identifiers, compatibility impact, and tests or
vectors. Changes to normative bytes, ordering, schemas, registries, or failure
meaning require matching prose, machine-readable assets, examples, and tests.

Run `python -m pytest -q` and `python validator/validate_examples.py` before
submission. Do not rewrite frozen Profile 3 assets or assign new permanent
registry identifiers without explicit maintainer review.
